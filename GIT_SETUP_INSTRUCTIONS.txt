ШАГ 1. Создать новый репозиторий на GitHub
──────────────────────────────────────────
• Зайдите на https://github.com/new
• Repository name: 10Systemrisks (или любое имя)
• Public
• НЕ ставьте галочки: "Add a README", "Add .gitignore", "Choose a license"
  (репозиторий должен быть пустым)
• Нажмите "Create repository"


ШАГ 2. Запустить скрипт на своём компьютере
──────────────────────────────────────────
В терминале:

  cd /Users/vladimir_a/Desktop/10SystemRisks
  chmod +x git_fresh_push.sh
  ./git_fresh_push.sh

Скрипт: удалит старый .git, создаст новый репо, добавит файлы (без .md),
        сделает коммит и отправит на origin main.


ШАГ 3. Если репозиторий создали под другим именем или другим URL
────────────────────────────────────────────────────────────────
Откройте git_fresh_push.sh и в строке с git remote add origin
замените URL на свой, например:

  https://github.com/v7221851-dev/ДРУГОЕ_ИМЯ.git


ШАГ 4. Если при push просят логин и пароль
──────────────────────────────────────────
• Username: ваш логин GitHub (v7221851-dev)
• Password: не пароль от аккаунта, а Personal Access Token
  Создать: GitHub → Settings → Developer settings → Personal access tokens
  → Generate new token (classic), права repo → скопировать токен и вставить как пароль
