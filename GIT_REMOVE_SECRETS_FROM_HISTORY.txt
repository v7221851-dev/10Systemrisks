# Удаление секретов из истории Git

GitHub блокирует push, потому что в истории Git есть коммиты с секретами.
Нужно удалить эти файлы из всей истории.

Выполните команды по порядку:

# 1. Убедитесь, что вы на ветке main
git checkout main

# 2. Удалить файлы с секретами из всей истории Git
git filter-branch --force --index-filter \
  "git rm --cached --ignore-unmatch RAILWAY_ENV_VARS.txt STREAMLIT_SECRETS_CLEAN.toml STREAMLIT_SECRETS_FIXED.toml STREAMLIT_SECRETS_TEMPLATE.toml" \
  --prune-empty --tag-name-filter cat -- --all

# 3. Принудительно обновить удалённый репозиторий (ОСТОРОЖНО: перезаписывает историю!)
git push origin --force --all

# 4. Очистить локальные ссылки
git for-each-ref --format="delete %(refname)" refs/original | git update-ref --stdin
git reflog expire --expire=now --all
git gc --prune=now --aggressive

ПРЕДУПРЕЖДЕНИЕ:
- Force push перезаписывает историю на GitHub
- Если кто-то ещё работает с репозиторием, им нужно будет пересинхронизировать
- Убедитесь, что у вас есть резервная копия перед force push
