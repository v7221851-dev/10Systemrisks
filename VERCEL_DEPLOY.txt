  ДЕПЛОЙ НА VERCEL (лендинг проекта)
═══════════════════════════════════════════════════════════════

На Vercel разворачивается только информационная страница (HTML).
Полноценное Streamlit-приложение там не запускается — для него используйте
Streamlit Community Cloud (share.streamlit.io).

───────────────────────────────────────────────────────────────
СПОСОБ 1: Через сайт Vercel (рекомендуется)
───────────────────────────────────────────────────────────────
1. Зайдите на https://vercel.com и войдите через GitHub.
2. Нажмите "Add New..." → "Project".
3. Импортируйте репозиторий: выберите v7221851-dev/10SystemRisks
   (если не виден — нажмите "Import Git Repository" и введите URL репо).
4. Настройки оставьте по умолчанию:
   - Framework Preset: Other
   - Build Command: пусто
   - Output Directory: пусто
   - Root Directory: ./
   Vercel сам подхватит vercel.json и соберёт api/index.py.
5. Нажмите "Deploy".
6. После сборки получите ссылку вида: https://10-system-risks-xxx.vercel.app

───────────────────────────────────────────────────────────────
СПОСОБ 2: Через Vercel CLI
───────────────────────────────────────────────────────────────
1. Установите CLI (один раз):
   npm i -g vercel

2. В корне проекта:
   cd /Users/vladimir_a/Desktop/10SystemRisks
   vercel

3. Следуйте подсказкам:
   - Link to existing project? Yes → выберите проект или создайте новый
   - Или: Set up and deploy? Yes

4. Продакшен-деплой:
   vercel --prod
